Why Prism

Research computing, without the setup tax

Prism runs in your own AWS account and handles the parts researchers shouldn't have to: instance choice, storage, provisioning, and cost.

⚡

Launch in seconds

One command picks the right instance, configures storage, and installs your tools. prism workspace launch python-ml my-project.

💰

Cost control built in

Per-project budgets with live enforcement, spot pricing, idle detection, and automatic hibernation — no surprise bills.

🧪

Research-ready templates

Python ML, R/RStudio, genomics, bioinformatics — pre-configured with the tools your field actually uses.

👥

Built for labs & classes

Provision workstations for a whole class via invitation codes. Projects, budget pools, and per-student usage tracking.

🖥️

CLI and desktop app

Script it from the terminal or manage visually in the desktop app. Both share one always-on daemon.

🔒

Your account, your data

Runs in your AWS account with per-project IAM scoping, SSH key management, and encrypted storage. Nothing leaves your control.

Get started

Up and running in minutes

Install Prism, authenticate with AWS, and launch your first workspace.

# 1. Install
brew install scttfrdmn/tap/prism

# 2. Authenticate with AWS (browser login)
aws login

# 3. Launch your first workspace
prism workspace launch python-ml my-project
# 1. Install (Scoop)
scoop bucket add scttfrdmn https://github.com/scttfrdmn/scoop-bucket
scoop install prism

# 2. Authenticate with AWS
aws login

# 3. Launch your first workspace
prism workspace launch python-ml my-project
# 1. Download the latest release from
#    github.com/scttfrdmn/prism/releases/latest
tar xz -f prism_<version>_linux_amd64.tar.gz
sudo mv prism prismd /usr/local/bin/

# 2. Authenticate with AWS
aws login

# 3. Launch your first workspace
prism workspace launch python-ml my-project
How it works

From zero to workstation

1

Pick a template

Choose from research-ready environments, or run prism init for a guided first launch.

2

Launch

Prism sizes the instance, sets up storage and SSH, and provisions your tools automatically.

3

Work

Connect over SSH or open Jupyter/RStudio in your browser via a secure tunnel.

4

Stop paying

Hibernate or stop when idle — automatically. Storage persists; compute cost doesn't.
