    v0.5.9 Implementation Plan: Navigation Restructure¶

    Target Release: January 3, 2026 Duration: 2 weeks (December 16-27, 2025) Status: 📋 Planning Phase

    Executive Summary¶

    v0.5.9 focuses on reducing navigation complexity from 14 items → 6 items, making Prism's interface more intuitive for new researchers while maintaining access to advanced features for power users.

    Current State Analysis¶

    GUI Navigation (App.tsx:6586-6641): 

    Current: 8 visible top-level items
1. Dashboard
2. Templates
3. My Workspaces (instances)
4. Terminal ← TO REMOVE
5. Web Services ← TO REMOVE
6. Storage
7. Projects
8. Settings (contains Advanced group with AMI, Rightsizing, Idle, etc.)

    TUI Navigation (app.go:30-62): 

    Current: 17 pages total
Core Pages (visible):
1. Dashboard
2. Instances
3. Templates
4. Storage
5. Projects
6. Budget
7. Users
8. Settings

Advanced Pages (need to be nested):
9. AMI
10. Rightsizing
11. Idle Detection
12. Policy
13. Marketplace
14. Logs
15. Daemon
16. Profiles

    Key Finding: GUI already has advanced features in Settings > Advanced group (App.tsx:3877-3888), but Terminal and Web Services are still top-level items. TUI needs more restructuring.

    Risk Assessment¶

    Low Risk¶

    • ✅ Terminal/WebView views exist, just moving access method
    • ✅ GUI Advanced features already in Settings (no regression risk)
    • ✅ Storage tabs are additive (existing functionality preserved)

    Medium Risk¶

    • ⚠️ TUI submenu is new functionality (needs thorough testing)
    • ⚠️ Workspace actions need good error handling

    Mitigation¶

    • Start with GUI changes (lower risk)
    • Test TUI submenu independently before integration
    • Keep old navigation code commented out temporarily (easy rollback)

    Rollback Plan¶

    If critical issues found post-release: 1. Revert navigation changes (git revert) 2. Hotfix minor bugs in v0.5.9.1 3. Keep Terminal/WebView accessible via URL if navigation removed
